# Bruna Magalhães — Link bio

Abra VER-PROJETO.bat ou index.html. Para a prévia com servidor, execute node preview-server.cjs e abra http://127.0.0.1:4174/. Requer Node.js apenas para o servidor.

Os contatos ficam em assets/config.js. WhatsApp incompleto ou vazio direciona o contato para o Instagram. Informe o número completo e o CRP confirmado quando disponíveis.

Inclui versões desktop e mobile, apresentação, detalhes online e presencial, navegação por teclado e animações GSAP com respeito à preferência de movimento reduzido. Fontes e GSAP usam CDN e precisam de internet; o conteúdo funciona sem esses recursos.
